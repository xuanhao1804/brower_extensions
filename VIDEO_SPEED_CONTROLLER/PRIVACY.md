# Privacy Policy for Video Speed Controller

Effective date: September 18, 2026

Video Speed Controller is a browser extension that lets users control the
playback speed of HTML5 videos with keyboard shortcuts, mouse gestures, speed
presets, and an on-video controller.

## Data collection

Video Speed Controller does not collect, transmit, sell, or share personal
information, browsing history, website content, authentication information, or
analytics data.

The extension does not use advertising, tracking technologies, or external
analytics services.

## Settings stored by the extension

The extension uses the browser's storage API to save user-configurable
preferences, including:

- Default playback speed and adjustment step.
- Speed presets.
- Keyboard shortcuts.
- Mouse wheel preferences.
- On-video controller visibility and opacity.

These settings are stored by the browser and may be synchronized between the
user's browser installations when browser synchronization is enabled. The
developer does not operate a server that receives or stores these settings and
does not have access to them.

## Website access

The extension runs on webpages to detect HTML5 video elements and change their
playback speed when requested by the user. This processing takes place locally
in the browser.

The extension does not record or transmit visited URLs, browsing activity,
video content, page content, or information entered on webpages. Access to
embedded frames is used only to support video players contained within iframes.

## Remote code and third parties

The extension does not download or execute remote code. All executable code is
included in the extension package. No user data is provided to third parties.

## Data retention and deletion

The extension retains only its user-configurable settings through the browser's
storage system. Users can reset these settings from the extension popup or
remove locally stored extension data by uninstalling the extension. Synced data
is managed by the user's browser account and browser provider.

## Changes to this policy

This policy may be updated if the extension's functionality or data practices
change. Material changes will be reflected on this page with an updated
effective date.
